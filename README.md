# ShipShoot

**ShipShoot** 是一个使用 C++ 编写的简单 2D 像素射击游戏原型，使用
[GLFW](https://www.glfw.org/) 和 [GLAD](https://glad.dav1d.de/) 进行 OpenGL
渲染。

## 特性

- 摄像机平滑跟随玩家
- WASD / 方向键移动，鼠标/键盘瞄准
- 左键射击；子弹留下短暂的轨迹，撞击时产生火花效果
- 右键朝光标方向冲刺
- 过热系统：射击会积累热量，飞船颜色在接近上限时从绿→黄→红变化
- 敌人生成在当前视野之外并追踪玩家
- 敌人需承受 20 次命中，受到伤害时闪白
- 与敌人碰撞即游戏结束

## 构建

该项目使用 CMake。 在安装了所需库的类 Unix 系统上运行：

```sh
cd /home/jomoarch/ShipShoot
mkdir build && cd build
cmake ..
make

# 可执行文件位于 build/ShipShoot
```

依赖项：

- 支持 C++14 的编译器（gcc/clang）
- GLFW 开发头文件
- OpenGL 3.3 或更高版本

（你可以通过包管理器安装 GLFW 和 GLAD，或从源码构建；GLAD 已包含在
仓库的 `glad/` 目录下。）

## 控制

| 输入     | 操作               |
| -------- | ------------------ |
| W / ↑    | 向上移动           |
| S / ↓    | 向下移动           |
| A / ←    | 向左移动           |
| D / →    | 向右移动           |
| 鼠标移动 | 瞄准飞船           |
| 左键     | 射击子弹（会过热） |
| 右键     | 朝光标方向冲刺     |
| ESC      | 退出               |
